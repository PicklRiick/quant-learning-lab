Lesson 0003

Python 金融数据最小工作流

这节课只学一条从价格到策略收益的管道：读取、检查、排序、收益率、滚动指标、信号延迟。

预计时间：20-25 分钟 打开速查 打开资料笔记

本课的一个胜利

你会看懂一段最小 pandas 回测前处理代码，并能指出哪里在避免未来函数。pandas 官方教程强调读取 CSV 后要先检查数据，时间序列文档也把日期解析、重采样、时区和业务日作为核心能力。

价格不是策略输入的终点

价格本身有单位，不能直接比较不同资产；收益率才是回测里的基本货币。pandas 的 pct_change() 返回的是 fractional change，例如 0.01 代表 1%，不是已经乘以 100 的百分数。

df["ret"] = df["close"].pct_change()

滚动窗口是第一批指标

pandas 的 windowing API 支持 rolling、expanding 和 exponentially weighted window。第一阶段只需要 rolling：移动均线、滚动波动率、滚动最高/最低点都来自同一类思想。

df["ma200"] = df["close"].rolling(200).mean()
df["vol60"] = df["ret"].rolling(60).std()

最关键的一行：shift

如果一个信号用到了今天收盘价，那么今天收盘前你并不知道它。第一版向量化回测必须把信号延后一格，表示下一期才持仓。

df["signal"] = (df["close"] > df["ma200"]).astype(int)
df["position"] = df["signal"].shift(1)
df["strategy_ret"] = df["position"] * df["ret"]
没有 shift(1) 的入门回测，大概率在偷吃今天已经发生的收益。
收益模型的边界：上面的 close-to-close 收益乘延迟持仓，仅用来演示时间对齐。它并未模拟 t+1 日开盘成交，不能直接代表前课策略卡的执行方式。正式回测需使用开盘价、可成交时点及成本来重建收益。

快速小测

今天收盘信号应当用于哪期收益？
