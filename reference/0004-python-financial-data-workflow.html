Reference 0004

Python 金融数据工作流速查

第一阶段只需要一条纪律：先把时间和收益率弄对，再谈指标和策略。

最小流程

  1. 读取数据：pd.read_csv。
  2. 检查数据：head()、info()、dtypes、缺失值、重复日期。
  3. 建立时间索引：把日期列转成 DatetimeIndex，并按时间排序。
  4. 计算收益率：close.pct_change()。
  5. 计算滚动指标：rolling(window).mean()、rolling(window).std()。
  6. 生成信号：把价格条件转成 0/1 或 -1/0/1。
  7. 延迟执行：signal.shift(1)，避免用今天收盘信号吃到今天收益。

核心代码形状

df = pd.read_csv("prices.csv", parse_dates=["date"])
df = df.sort_values("date").set_index("date")
df["ret"] = df["close"].pct_change()
df["ma200"] = df["close"].rolling(200).mean()
df["vol60"] = df["ret"].rolling(60).std()
df["signal"] = (df["close"] > df["ma200"]).astype(int)
df["position"] = df["signal"].shift(1)
df["strategy_ret"] = df["position"] * df["ret"]

常见错误

没有时间索引

金融数据不是普通表格，日期顺序和可见时间会改变结论。

收益率当价格用

价格有单位，收益率可比较；策略收益应基于收益率。

没有 shift

今天收盘后才知道的信号，不能用于今天已经发生的收益。

滚动窗口太短

窗口越短噪声越大，窗口越多过拟合风险越高。
