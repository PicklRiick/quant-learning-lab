Reference 0003

市场信号地图

写策略假设卡前，先把信号放到正确位置：方向、过滤器、仓位、风险、执行。

信号不是预测口号

一个市场信号是一个可观察变量，它应该改变某个明确决策：买卖方向、是否交易、仓位大小、风险限额或执行方式。不要问“这个指标准不准”，先问“它改变哪一个动作”。

七类基础信号

趋势 / 动量

过去强的是否继续强。常见变量：过去 N 日收益、均线突破、相对强弱排名。第一张卡优先从这里开始。

均值回归 / 反转

价格是否偏离近期参考点太远。常见变量：均线偏离、z-score、短期极端涨跌。它对持有期和成本很敏感。

波动 / 风险状态

不确定性是否升高。常见变量：历史波动率、VIX、波动率分位数。它通常更适合做仓位或过滤器。

成交量 / 流动性

价格变动是否有交易参与支持，交易是否可执行。常见变量：成交额、换手率、买卖价差、冲击成本。

市场宽度 / 参与度

指数上涨是否由多数资产参与。常见变量：上涨家数、下跌家数、成分股在均线上方比例。

情绪 / 仓位

参与者是否过度乐观或恐慌。常见变量：put/call ratio、VIX、COT 持仓、资金流。

宏观 / 基本面

资产处在什么经济环境。常见变量：利率、通胀、美元、信用利差、估值、盈利、库存。

四个位置

Alpha 信号

决定方向：做多、做空或不持有。例如趋势突破、价值排名、期限结构。

过滤器

决定是否启用 alpha。例如高波动时暂停，低流动性时不交易。

仓位规则

决定押多少。例如波动率越高仓位越低，最大组合仓位不超过某比例。

执行假设

决定如何成交。例如下一日开盘、市价单、限价单、滑点和手续费。

第一张卡的推荐组合

一个 alpha + 一个风险过滤器。 不要一开始就混合五个因子。建议用趋势作为 alpha，用波动率作为过滤器，因为两者概念清楚、数据容易取得、错误也容易暴露。 
Signal family: 趋势 / 动量
Entry: close > 200-day moving average AND 60-day return > 0
Filter: realized volatility < its 60-day 80th percentile
Exit: close < 200-day moving average
Costs: transaction fee + slippage
Evaluate: return, max drawdown, Sharpe, turnover, trade count
